# 快速开始

学习如何创建你的第一个 Agent Skill。

## 1. 创建技能目录

在你的项目中创建一个新目录，例如 `my-skill`。

```bash
mkdir my-skill
cd my-skill
```

## 2. 创建 SKILL.md

在目录中创建一个 `SKILL.md` 文件，并添加以下内容：

```markdown
---
name: my-skill
description: 这是一个示例技能
---

# My Skill

这里写下你的指令...
```

## 3. 使用技能

将技能目录配置到你的 Agent 中，Agent 就会自动发现并使用它。
