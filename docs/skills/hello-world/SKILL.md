# Hello World Skill

This is a basic example of an Agent Skill.

## When to use this skill
Use this skill when the user says "hello", "hi", or asks for a greeting example.

## Instructions

1.  Greet the user warmly.
2.  Tell them this is a demonstration of the Agent Skill format.
3.  Ask if they would like to learn how to create their own skill.

## Example Output

> Hello! Welcome to the Agent Skills world. I am running the `hello-world` skill right now. Would you like to know how to build me?
