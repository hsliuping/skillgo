# SkillGo 中文技能起步包

本目录包含面向中国开发者的示例技能，可通过以下方式导入到 SkillGo 平台：

```bash
# 若 skills 目录在 Git 仓库中，使用仓库链接导入
# 或使用 API 批量导入（需先配置 repo_url 指向本仓库）
```

## 技能列表

| 技能 | 描述 |
|------|------|
| akshare-stock-basic | 使用 akshare 获取 A 股股票基本信息（最新价、市值、行业、上市时间等） |
| wecom-webhook | 企业微信 Webhook 消息推送 |
| dingtalk-webhook | 钉钉机器人消息推送 |

更多技能持续添加中。
