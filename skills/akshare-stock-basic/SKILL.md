# A股股票基本信息

使用 akshare 库从东方财富获取 A 股股票的基础信息。

## 依赖

- Python 3.8+
- akshare

## 使用场景

当需要查询股票代码、名称、最新价、总股本、流通股、总市值、流通市值、行业、上市时间等基础信息时使用。

## 输入参数

- `symbol`: 股票代码，6 位数字，如 `000001`（平安银行）、`600519`（贵州茅台）、`603777`（来伊份）

## 输出

返回包含以下字段的 JSON 对象（具体字段以 akshare 接口为准）：

- `最新`: 最新价
- `股票代码`: 股票代码
- `股票简称`: 股票名称
- `总股本`: 总股本数量
- `流通股`: 流通股数量
- `总市值`: 总市值（元）
- `流通市值`: 流通市值（元）
- `行业`: 所属行业
- `上市时间`: 上市日期

## 示例

```json
{
  "input": {
    "symbol": "600519"
  }
}
```

返回示例（贵州茅台）：

```json
{
  "最新": 1680.5,
  "股票代码": "600519",
  "股票简称": "贵州茅台",
  "总股本": 1256000000.0,
  "流通股": 1256000000.0,
  "总市值": 2110768000000.0,
  "流通市值": 2110768000000.0,
  "行业": "酿酒行业",
  "上市时间": 20010827
}
```
